# Journée Carrière UIST / 2ITS

## Application web progressive

Le site peut être installé depuis un navigateur compatible et son interface reste accessible hors ligne après une première visite. Les inscriptions et l'espace administrateur nécessitent toujours une connexion Internet, car ils utilisent le serveur Google Apps Script.

Pour activer l'installation et le mode hors ligne, publiez les fichiers du site sur un hébergement HTTPS (ou lancez-le sur `localhost`). Gardez `manifest.webmanifest`, `service-worker.js`, le dossier `icons/`, les deux logos et les deux photos du bandeau au même niveau que `index.html`.

Les icônes de l'application sont générées à partir de `logo-uist.jpg`.
